# 用語の書き方・調査の基準

対象読者は教員採用試験・教職課程の学生と現職教員。**正確さ最優先、平易な文章**。

## 1. 調査(必須)

- 追加する用語は**必ず Web 検索・論文/データベースで確認**する。記憶のみで書かない。
- 優先する情報源(上ほど優先):
  1. 一次情報: 文部科学省(mext.go.jp)、e-Gov 法令検索、国立教育政策研究所、中央教育審議会答申、こども家庭庁、各国政府・OECD・UNESCO・IEA 等
  2. 学術: J-STAGE、CiNii、KAKEN、CiNii Books、Google Scholar、arXiv(教育工学・AI 関連)
  3. 事典・信頼できる解説: 教育学事典、大学・研究機関の公開資料
- 確認すること: 提唱者・年・法令名と条文番号・制度の開始/改正年・数値(定義・基準値)。ソースが食い違う場合は一次情報を採り、断定できないことは書かない。
- Wikipedia 単独は根拠にしない(手がかりとして使い、一次情報で裏取りする)。
- 時事・制度は「現時点」を明記する(例:「2024年時点」)。改正で古くなりやすい項目は年を入れる。

## 2. 文章

- `summary`: 30〜220字。一覧カードに出る。定義+要点を1〜2文で。
- `body`: 300〜600字目安、3段落程度。段落は `\n\n`。構成の例: ①定義・提唱者/制度の内容 ②背景・意義・具体例 ③関連・批判・現在の動向。
- 文体: 「〜である/〜とされる」または「〜です/〜ます」のどちらかに**一つの用語内で統一**(既存は両方あるため、同じ分野の近い項目に合わせてもよい)。
- 人名: 日本語表記(原綴は括弧)。例:ヴィゴツキー(Vygotsky)。ただし旧字体の固有名詞(國分康孝・慶應義塾・澤柳政太郎など)は正式表記を保つ。
- 略称は初出で正式名称を併記する。数値・年は半角数字、期間は「〜」。
- **英文や中国語を混ぜない**(固有名詞の原綴・略語は可)。簡体字は禁止(`遊`→`游`のような誤り、`钣` `抖` `遗` など)。
- 断定できない主張・未確認の統計は書かない。批判的見解は「〜という批判もある」と出典の性質が分かる形で。

## 3. メタデータ

- `slug`: ローマ字(ヘボン式でなくてよい)か英語の kebab-case。一意。既存の流儀に合わせる(例: `gakushu-shido-yoryo`, `zpd`)。
- `reading`: ひらがな。長音は「ー」、中黒は「・」。数字は半角で可(例: `ゔぁいんらんど2てきおうこうどうしゃくど`)。括弧書きは付けない方がよい。
- `kana`: 空欄でよい(`npm run ingest` が自動計算する)。ルール: 英字始まりの題名 → `A–Z`、それ以外は読みの先頭1字を清音・大文字化(が→か、っ→つ、ゔ→う)。数字始まりの題名は読みで判断。
- `categories`: 先頭が主分野。ほか最大2つまで。
- `relatedSlugs`: **実在する** slug のみ(3〜6件)。双方向である必要はない。同じ概念の別名・略称は**別項目にせず**、題名に括弧で併記する(例:「要保護児童対策地域協議会(要対協)」)。
- `tags`: 3〜6語。検索に使われる語(別名・略称・年・人名)。
- 図解(`diagram`): 段階・階層・並列要素が明確な用語のみ。`pyramid`(階層)/`concentric`(同心円)/`columns`(並列)。項目は3〜7個、`label` は短く。

## 4. 重複・既存との関係

- 追加前に `grep -rn "題名の一部" src/data/terms` と `npm run validate` で確認。
- 検証が検出する重複: slug 重複、題名の完全一致、括弧書きを除いた題名の一致、読みの一致(警告)。
- 既存用語の内容が不足/誤りだと気づいたら、**自分で書き換えず**「申し送り」に書く(Claude Code が訂正する)。

## 5. 追加後の確認

`npm run validate` → `npx tsc --noEmit` → `npm run build`。エラー 0 になるまでマージしない。
警告「JIS第1水準外の漢字」が出たら、その字が本当に必要な字か(誤字・中国語字形でないか)確認する。必要なら `scripts/data/rare-kanji-allowlist.txt` に追記してよい。
